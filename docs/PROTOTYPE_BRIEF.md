# 共通プロトタイプ条件

**ステータス: 検証中（2026-11-20時点）。** 2人が同じ出発点から試作するための合意事項を整理する。細部が未決なら勝手に確定した仕様にしない。

## ユーザーが決めた方向性
- iOS向け、Swiftで作る。
- 人型の、窓に投げるとぺたっと張り付く粘着おもちゃを使う。
- 一度の挑戦で人形を **3体** 投げる。
- 星座を作る／星座に寄せることが中心。人形は小さい頭と長い手足で、変な形になる。
- 投げ方・角度によって着地ポーズが変わる。
- **同じ条件から同じように投げたとき、同じ形に着地する**。乱数任せにしない。
- 北風・太陽・ドーナツの要素はこの企画から除外する。
- まずは2D試作を想定。ただしデザイン担当と相談するため **2D/3Dは未決定**。

## 共有する検証観点（提案）
1. 初見で「人形を投げて星座を作る」が伝わるか。
2. スワイプや角度を変えると、結果を狙って変えられるか。
3. 2投目・3投目に工夫の余地があるか。
4. 手足が張り付く気持ちよさ、失敗時の面白さがあるか。
5. 同条件の投擲結果が再現できるか（盤面状態・投擲順を含む）。

## まだ決めていない
- 星座の点を何で判定するか（頭・手足の先端・関節など）
- 点の一致度・得点・クリア条件・投げ直し
- 3体の人形同士を衝突させるか、先に着地したものは固定するか
- ポーズの種類と計算式、投擲の入力形式
- 2D/3D、素材・アート方向、画面向き、音、課金
- 正確な対応iOSバージョン（現時点の基盤はiOS 17を暫定設定）

両プロトタイプはこれらの未決事項にそれぞれ仮説を立てて実装してよい。ただし、仮説と結果を各ブランチの `docs/` に残す。
