# ゲームデザイン検討メモ — ぺたっと星座！

- 最終更新: 2026-11-20
- 状態: **プロトタイプで検証する仮説**（確定仕様と区別）

## 核となる遊び
3体の小さな頭・長い手足の人型粘着人形を壁へ投げて、星座の「点と線」を作る iOS ゲーム。投げ方に応じた変な姿勢で人形が張り付く。物理的な見た目はコミカルだが、プレイヤーが再現・上達できるパズルにする。

## 確定・合意していること（ユーザー発言）
- iOS / Swift。
- 北風・太陽・ドーナツは採用しない。
- 3体程度を順に投げる。
- 投げる方向・角度などに応じてポーズが変わる。
- **同じ条件で投げたら同じ形になる**（再現性が必要）。
- 人形は小さな頭と長い手足で、星座に見えるようにする。
- 最初は2Dで試す可能性が高いが、2D/3Dの採用はデザイン担当と相談して決める。

## プレイの流れ（試作仮説）
1. 1画面に星座の点（目標）が現れる。
2. 人形1体目を指で投げ、どこに張り付くか観察する。
3. 投げ方と固定姿勢を踏まえ、2体目・3体目で星の位置を埋める。
4. 3体投げ終えたら一致度を表示。再試行できる。

**未確定:** 星に合わせるのは手足の先端か、頭・関節も含むか。線の接続・採点方法、評価閾値、投げ直し回数、失敗条件。

## 競技性・笑いの両立
- 操作入力と盤面が同じならポーズが再現される。投擲コースや角度を覚えると上達する。
- くっつくときのぐにゃっとした変形・効果音・表情は結果を変えない演出として分離する。
- 3投目が前の人形を動かすかどうかは試作結果で判断する。
- 上達の観察に「前回の軌跡」「投擲履歴」を使う案。ただしMVPには必須でない。

## 2つの試作で比較したいこと
| 観点 | 確認方法 |
| --- | --- |
| 最初の理解 | 説明なしで初投できるか |
| 操作の手応え | 距離・角度を狙って調整できるか |
| 星座らしさ | 3体の配置が点と線に見えるか |
| 再現性 | 同じ初期状態・入力系列でポーズが一致するか |
| リトライしたさ | 失敗後、どこを改善すべきか分かるか |
| 開発コスト | 実装の複雑さ、描画・モデル制作コスト |
| iOS相性 | タッチ操作、FPS、画面サイズ |

「先に作れた方を採用」ではなく、体験を比較する。2人が試す仕組みや絵作りは独立でよい。

## 直近の技術検証
1. 投擲入力を定義し、変換結果が決定的になる純粋なSwift処理のテストを作る。
2. 壁への付着位置・最終姿勢を表示する最小ステージを作る。
3. スワイプ・ドラッグ・リリースでの操作感を計測する。
4. 動きの物理表現と固定ポーズ計算を分離できるか確認する。

## 保留・議論ポイント
- 2D / 3D、カメラ視点、画面向き
- ポーズは連続変形か少数の基本姿勢を補間するか
- 貼り付けた人形同士の衝突を許すか
- 星座を完成させるまでの正確な得点条件
- 星座のお題、世界観、アート、レベル設計
- デイリーチャレンジ・SNS共有・課金の優先度
